# ИИ-ассистент для мониторинга клиентских коммуникаций

**Наименование проектной задачи**  
Разработка интеллектуального ассистента для мониторинга и анализа коммуникаций с клиентами.

**Заказчик**  
ООО «НТО «ИНТ» (Vedita)

**Цель проекта**  
Повышение качества клиентского взаимодействия посредством автоматизированного контроля коммуникаций, своевременного выявления обращений, требующих реакции, и информирования ответственных сотрудников о потенциальных рисках.

**Описание проектной задачи**  
В рамках проекта предусматривается разработка интеллектуального ассистента, осуществляющего анализ переписки в клиентских чатах Telegram и MAX с учётом контекста взаимодействия и содержания проектной документации.

Система должна выявлять:

- обращения и вопросы клиентов, на которые не был предоставлен ответ;
- обязательства, требующие исполнения со стороны ответственных сотрудников;
- случаи несвоевременного предоставления оценок, результатов и иной информации;
- претензии, негативные оценки и иные признаки неудовлетворённости клиента;
- запросы на предоставление счетов, универсальных передаточных документов, смет и иных документов;
- ситуации, требующие внимания менеджера проекта или руководителя.

Для каждого клиентского чата должен определяться уровень приоритетности реагирования. Система должна формировать краткое описание выявленной ситуации и рекомендации по необходимым действиям.

Результаты анализа должны предоставляться ответственным сотрудникам с установленной периодичностью посредством Битрикс24, Telegram или специализированного пользовательского интерфейса.

В дальнейшем возможно расширение функциональных возможностей системы за счёт автоматического создания задач в Битрикс24, маршрутизации запросов профильным сотрудникам и информирования клиентов о результатах выполнения работ.

**Ожидаемые результаты проекта**

- Создание прототипа интеллектуального ассистента для анализа клиентских коммуникаций.
- Обеспечение автоматического выявления обращений, требующих реакции ответственного сотрудника.
- Формирование сводной информации о состоянии коммуникаций по каждому клиентскому чату.
- Присвоение выявленным ситуациям уровня приоритетности.
- Формирование краткого описания ситуации и рекомендаций по дальнейшим действиям.
- Реализация настройки ответственных сотрудников, периодичности анализа и каналов уведомления.
- Сокращение количества клиентских обращений, оставшихся без своевременного ответа.
- Сокращение времени реагирования на претензии и критически значимые обращения.
- Повышение прозрачности и управляемости процессов клиентского взаимодействия.
