THROWAWAY Prototype: Cognee Backend Isolation and Shadow Activation

This demo answers one question: can a Spine-owned ContextProjection state model use Cognee 1.5.4 as a rebuildable projection while preserving two-workspace isolation, provenance round-trip, update/delete semantics, full shadow rebuild, validation, atomic active-version switching, rollback, and concurrency safety?

Prototype branch primary source only. This file is deliberately not production code and must not be merged as a production implementation.
